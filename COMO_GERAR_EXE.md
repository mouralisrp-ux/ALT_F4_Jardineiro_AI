# ALT F4 Jardineiro AI — Build automático Windows

1. Cria um repositório novo no GitHub.
2. Envia todos os ficheiros deste ZIP para o repositório.
3. Abre **Actions**.
4. Escolhe **Build ALT F4 Jardineiro AI**.
5. Clica em **Run workflow**.
6. Quando terminar, abre o resultado e descarrega `ALT_F4_Jardineiro_AI-Windows`.
7. Dentro do ZIP estará `ALT_F4_Jardineiro_AI.exe`.

O computador onde o EXE for usado não precisa de Python.
